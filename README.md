# Trivia

A lightweight, framework-free static website starter for a trivia site.

## Project structure

```text
.
├── index.html
├── css/
│   └── styles.css
└── js/
    └── main.js
```

## Run locally

Open `index.html` in a browser, or serve the project directory with any static
file server. No build step or dependencies are required.

Edit `index.html` for page content, `css/styles.css` for presentation, and
`js/main.js` for browser interactions.
